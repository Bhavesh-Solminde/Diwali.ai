## Verdict

**Do not accept current vendor outputs for synthetic pretraining.** Useful diagnostics include exact boundary levels, last trade, source-removal call provenance and synchronous fill-transfer ledgers under declared host settings. They do not repair the economic or temporal defects. Existing diagnostic datasets and conclusions stay immutable and separate from any future corrected dataset.

Preferred next paths, for review only:

1. Obtain a supported corrected exporter with per-execution timestamp/sequence, price, quantity, order lifecycle, fees, reservation transitions and complete state/RNG replay; verify invariants and label provenance against recorded events.
2. Alternatively design an independently implemented event engine with explicit matching/FIFO, reservation and cancellation unlock, partial/zero fills, trade-based candles/volume, conservation and replay tests. It would create a new versioned dataset, never silently replace the diagnostic files.

No vendor binary patch or replacement engine is built in this task. Real-data pipeline work and a later small real-only baseline do not need to wait for every simulator defect to be solved; each must pass its own acquisition, leakage and evaluation gates first.

# Amendment B: untouched v0.4 flow and prospective rule diagnostics

Written before collecting this new evidence. Earlier experiments and defects are known. No training, binary modification or live-process instrumentation is included. This amendment supplements native control evidence; it cannot replace native market measurements. The available UI has no verified numeric exporter or complete restorable RNG/state. Native snapshots cannot supply exact level depth or execution/cancellation reasons.

Use original DLL methods in a separate CLR host, with the existing explicit 200-agent profile (maker/request .1, activity/sweep .1, drop/candle .1, price 10000 raw cents, five sweeps/candle). Seed families differ from existing studies: ten pilot parents 31000–31009, thirty main 41000–41029. No interventions: 100 warmup plus 500 observed base candles per parent. Keep all attempts and errors. No real-minute mapping, no scene-default claim. No actual app backup/restore, bots or model fitting.

Record OHLC/true v0.4 executed volume, last trade, actual bid/ask sums, spread, 10-bp depth and level snapshots at each candle boundary. Separately snapshot before/after agent sweeps, pruning and random removal. Agent-sweep changes are NET additions/depletions (not individual executions or gross refill); pruning/random-removal reductions have known call provenance. No individual order IDs/ages are created. Level persistence means continuous nonzero presence across sampled candle boundaries. Within-sweep disappearance/recreation is unobserved.

Wall: positive level within 10bp of last trade, boundary persistence >=5 candles, quantity >=90th percentile of all positive level quantities in preceding 100 boundaries. Weak control: same distance/persistence requirements, quantity <= preceding median. For each side and strength, first eligible event in the 500-candle observation per parent; fewer eligible parents stay missing. Lock/cross or absent side at origin excludes that event, with counts. No switching definitions if rare. Outcomes: returns at +1/+5/+15/+30, favorable/adverse candle excursions, target/stop ±10bp relative to ORIGIN price; both hit in a candle is ambiguous, no hit by 30 is timeout. These are price-reaction proxies, not first-touch entry outcomes or executable profits. First-touch prospective bounce test remains separate.

Recovery for future intervention work: first completed candle whose signed displacement is <=half immediate displacement; censor at30. Sweep proxy: candle high-low >=preceding100-boundary 90th percentile and volume >=preceding volume90th; this cannot establish an individual aggressive sweep. Absorption candidate: volume>=past90th, abs(close/origin-1)<=5bp, and range<=past median; observe NET depth additions only, no hidden-order inference. History dependence: wall persistence strata and nearest-level distance are observable simulator features; individual age is unavailable.

Pattern diagnostics use prior20 candles only. Range: high-low <=median preceding100 rolling20 ranges. Triangle: increasing low OLS slope, decreasing high slope, terminal fitted width<=half initial width and positive widths. Flag: prior10-candle pole abs(return)>=2*sqrt(10)*past100 one-candle return SD and following10 retracement of opposite sign <=50% of pole. All are diagnostic strata, not trained signals. Fixed next-candle direction rules: recent close direction with ±1bp neutral; actual 10bp depth imbalance >.2/up, <-.2/down, else neutral; no-signal always neutral. Score ±1bp next-close classes with accuracy, balanced accuracy and class counts; missing/locked inputs excluded and counted. Compare per-parent paired accuracy deltas, stratified by each pattern, without tuning thresholds.

Ten pilots validate files/invariants, then thirty main parents. Verify event reductions nonnegative, v0.4 OHLC and volume, totals from levels, complete row counts and untouched preserved DLL hashes. Stop the collection on unhandled exceptions or corrupt/nonfinite prices, retain failures. Pilot variability is reported; 30 is a target, not proof of adequate power. All eligible origins within a parent are dependent. Bootstrap parents (2000 draws, fixed seed) for means/deltas, show event/parent denominators; no independent-candle confidence intervals. Main first-event wall summaries with fewer than10 parents are descriptive only. No probability calibration or 80% entry claim.

v0.5 existing original-host size/schedule/round-trip experiments remain valid within their profile, with independent exact aggregate-transfer ledgers. Current native lot100 differs from host size10. Do not pool native and host results. The revised report must say which requested experiments remain unmeasurable and distinguish this new collection from the existing 720 scenarios.

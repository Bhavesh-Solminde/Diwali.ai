# Research-to-model decisions — proposed v1.1

This supplements, rather than silently edits, the cloned repository's frozen v1 specification. No model training or trading was started. Confidence refers to the inspected builds and the controlled host, not generalization to live BTC.

| Previous assumption / proposal | Evidence | Revised decision | Confidence / unresolved question |
|---|---|---|---|
| v0.4 player Buy/Sell is a way to move the market | installed Long/Short only mark positions; isolated unchanged-depth checks | use v0.4 to inspect book mechanisms; do not treat these UI clicks as liquidity interventions | high for code; live controls not visually verified |
| v0.5 has enforceable finite agent inventories | no reservation calls; original methods oversell a 1-coin account; negative balances in 11/30 untouched main warmup parents | initialize finite inventory but require collateral reservation and fill-time constraints in our independent engine | high; prevalence outside the chosen profile unknown |
| visually persistent walls reveal ordinary economic support | v0.4 random deletion skips quantity >30; size filter reproduced 40/40 | stratify/flag simulator artifact; use order IDs, age, explicit cancellation policies in a new engine | high; real persistence must be measured independently |
| order aging / normal placement / ~10% makers describe exact mechanics | no birth times; triangular two-uniform offsets; maker choice per request with scene-set probability | use measured level persistence, document actual distribution/probability denominator; do not copy release-note shorthand into labels | high code, scene probability unknown |
| current depth totals and imbalance can be used directly | v0.4 wrong-side counters; integer division in taker imbalance both versions | calculate depth/imbalance from actual level quantities and own depth windows | high |
| raw simulator volume is executed coins | v0.5 player quantity multiplied by 100 | reconstruct base volume from a per-fill event ledger; separate player/agent source as diagnostic only | high |
| displayed OHLC preserves all trades | v0.5 records terminal price once per taker sweep | build OHLC per execution, test all intermediate prices; do not train on uncorrected displayed ranges | high |
| displayed PnL/position is ground truth | quantity missing; clicks advance on partial fill; integer entry averages | independently record cash, achieved quantity, fill prices, fees and mark price; reconcile realized/unrealized values | high |
| market cap estimates add independent predictive information | supply/stat formulas are derived from agent holdings, player nominal count and price | exclude these from deployable inputs; retain as simulator diagnostics | high |
| 100 is an enforced whale position limit | only market-cap formula uses 100; position method accepts 101 | label as accounting convention; do not use as exposure limit | high bookkeeping; live 101-fill scenario not tested |
| saved branches restore an identical state | v0.5 snapshot type exception, omitted FIFO/portfolios/RNG; v0.4 no RNG/mid-candle restore | reject app backup for paired causal studies; use full state/RNG snapshots only after validation | high |
| built-in GetNetworkInput/GetFuturePrices can supply learning examples | present book paired with price anchor 25 candles earlier, saturated bins, anchor included as label | write independent event-time input/target construction; preserve origin/availability times | high |
| 4,096 / ~16,000 candle claims prove usable 1,440-minute contexts | retention/windowing exists; field initializer 1,024; aggregation and actual scene capacities unknown | use 1,440 **real completed minutes** only when data supplies them; simulator base candles remain a separate domain | high structural, runtime capacity unresolved |
| whale spikes imply a profitable entry or liquidation | slippage grows with size, roundtrip means negative; LiqCycle only audio | train impact/recovery hypotheses, not a manipulation detector or liquidation label from shape | high within profile; real data needed |
| one-shot vs slices has an established best schedule | both paired slippage intervals include zero | keep schedule as experimental condition; no universal policy learned from this sample | moderate, needs broader profiles after engine correction |
| synthetic reserve/news can be taken from purchased sims | no such mechanism found in these scripts | reserve/news stay separate future engine work; real point-in-time news later; no invented vendor labels | high for inspected paths |
| cloning repository makes datasets and environments available | raw feeds/weights/environments excluded by Git; only results and code migrated | record missing dependencies explicitly; do not call saved results a new Windows replication | high |
| historical benchmark proves a winning neural model | saved report: imbalance balanced accuracy 37.09%, TLOB 35.24%, DeepLOB 34.16%; one budget/seed | keep strongest simple same-information baseline; venue provenance unresolved; no four-model winner | existing recorded evidence, not newly rerun training |
| hardware plan can be inherited from M5 Mac | current workspace Windows 10 / RTX 3060; prior Mac assumptions refer to another machine | profile the intended training machine after review; do not quote Mac throughput or inferred VRAM as Windows measurements | high |

Open questions that require actual live UI/export/source access: serialized trader count, maker/activity parameters, starting price, aggregation/capacity, native controls/rendering outcomes, robust durable frame capture, an author-supported numeric interface, and whether a corrected licensed build is available. No permission is needed to read the current evidence; patches and training are outside this research handoff.
